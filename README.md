# 轻松阅读（qingsongreader）

安卓原生电子书阅读器。Kotlin + Jetpack Compose 编写，**本地优先、无强制账号、无订阅、无 AI**：全部阅读功能离线可用，联网仅用于你主动开启的 WebDAV 同步、百度网盘导入、应用更新检查与英文单词在线释义，关闭这些后亦可完全离线使用——你读什么、读多久，只发生在你自己的设备上。

当前版本：**v0.5.6**（[更新日志](CHANGELOG.md)）

## 功能

### 阅读体验
- **格式**：EPUB / PDF / MOBI / AZW3 / TXT / Markdown
- **排版**：字号、行距、页边距、段距、两端/左对齐、衬线字体，实时生效
- **主题**：明亮 / 纸色 / 夜间，另有墨水屏模式（纯黑白、少残影，适配文石、掌阅等电纸书）
- **亮度与护眼**：阅读器内直接调节亮度（页面变暗，适合夜间），暖色护眼滤镜一键开关
- **分页 / 滚动**两种模式，音量键翻页、屏幕常亮可开关
- **默认沉浸阅读**：打开书籍即全屏（隐藏系统栏与全部工具栏），点屏幕中心以**浮层**形式调出上下工具栏——工具栏盖在文字上方，正文排版、分页与阅读进度分毫不变
- 退出阅读需二次确认，阅读进度自动保存

### 学习工具
- **选中即查词**：选中英文单词自动弹出词典，无需额外点击
- **词典**：内置汉字表（Unicode® Unihan）与 CC-CEDICT 汉英/英汉词典（约 11.4 万中文词条），完全离线；支持导入自定义 JSON/CSV 词表
- **批注**：四色高亮、笔记、书签，批注可导出 Markdown

### 书籍来源（SAF 存储访问框架）
- **从本机导入**：系统文件管理器，固定从本机 Download 目录打开，选中即导入
- **从网盘导入**：登录百度网盘授权后，直接选择网盘里的书籍文件（OAuth 授权登录，无需填写任何密钥）。授权页支持**扫码登录**（用百度 App 或百度网盘 App 的「扫一扫」扫描页面二维码，在手机上确认即可），也可切换账号密码登录；应用仅访问网盘「我的应用数据/个人阅读」目录（/apps/个人阅读），不会读取网盘中的其他任何文件
- **从 WebDAV 导入**：同样走系统文件选择器，直达你自己的 WebDAV 服务器（支持中文目录），选中即导入
- **后台下载 + 断点续传**：WebDAV 导书在后台进行，中途退出选择器或离开应用都不会中断；重新选择同一文件时从已下载字节处继续（HTTP Range），已完成的文件直接用缓存，秒级完成
- **导入进度可见**：书架顶部实时显示每个导入任务的进度
- **其他应用打开**：在微信、QQ、文件管理器里长按文件 →「用其他应用打开」→ 轻松阅读，直接导入

### 同步与统计
- **WebDAV 同步**：阅读进度、批注、书签与全部书籍文件同步到你自己的服务器，换机一键恢复；密码以圆点掩码显示
- **阅读统计**：阅读时长、进度回顾

### 应用内更新
- 检查更新走 GitHub Releases，下载支持**后台进行 + 断点续传**，按版本缓存安装包
- **加速镜像**：直连 GitHub 失败时（国内网络常见），可在「设置 → 关于与更新」中一键选择加速镜像（gh-proxy.com / ghfast.top / ghproxy.net）或自定义前缀，检查与下载都会走镜像

## 设计原则

1. **本地优先**：全部功能离线可用；联网仅限你主动配置的 WebDAV / 百度网盘 / 应用更新检查，以及查英文词时的在线释义（结果会缓存到本机）
2. **无 AI**：不调用任何大模型服务，不上传任何阅读数据
3. **无追踪**：不内嵌统计 SDK，不申请多余权限
4. **开源**：全部源码在本仓库，可自行构建

## 构建

要求：Android Studio（或命令行 Gradle 8.9 + JDK 17 + Android SDK 34）。

```bash
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

## 下载

到 [Releases](https://github.com/zwhapp/qingsongreader/releases) 页面下载最新 APK（debug 签名，直接安装）。国内访问 GitHub 慢或失败时，可在任意镜像前缀后拼接完整 Release 链接下载，例如 `https://gh-proxy.com/https://github.com/zwhapp/qingsongreader/releases/...`。
